# FlowLocal

**Зажали клавишу. Сказали. Отпустили. Слова уже в том окне, где вы печатали.**

Локальная диктовка для macOS: бесплатная замена [Wispr Flow](https://wisprflow.ai)
с открытым кодом. Звук и текст не покидают Мак — ни аккаунта, ни облака, ни подписки.

**Сайт:** [romankandeevy.github.io/flowlocal](https://romankandeevy.github.io/flowlocal/)

- **Быстро.** Речь разбирается прямо пока вы говорите: после отпускания клавиши
  текст появляется за ~0,1 с, даже после минуты диктовки.
- **Точно.** Русский — GigaAM v3 (сама ставит знаки препинания и пишет числа
  цифрами), английский — Parakeet TDT 0.6b. Смешанную речь язык определяет по кускам.
- **Чисто.** Слова-паразиты и повторы убираются, текст вставляется в любое приложение.
- **Под приложение.** В мессенджере — разговорно, в почте — строго, в коде —
  как сказано. Свой словарь имён и терминов; поправили слово — запомнит.
- **Код голосом.** В Xcode, VS Code и Терминале слушают обе модели сразу:
  русские слова — от GigaAM, английские — от Parakeet, склейка по словам.
  «Равно», «точка», «скобки», «кавычки» становятся знаками, английские слова —
  одним именем в camelCase; «снейк кейс», «паскаль кейс», «капс» меняют регистр;
  «комментарий …» — строка после `//`. Подробнее — ниже.
- **Шёпотом.** Режим шёпота поднимает чувствительность микрофона на время
  записи — можно диктовать вполголоса.
- **Бережно.** Прежний буфер обмена возвращается на место; каждая диктовка
  сохраняется в истории — её можно прослушать и перераспознать.
- **Вся история.** Текст диктовок хранится весь, без лимита (звук — у последних
  500). Сверху — календарь как на GitHub: щелчок по дню показывает его диктовки.

## Установка

Одной командой в Терминале:

```bash
curl -fsSL https://raw.githubusercontent.com/romankandeevy/flowlocal/main/mac/install.sh | bash
```

Или из клона репозитория:

```bash
cd mac && ./build.sh install
```

Нужны macOS 14+, Command Line Tools (или Xcode) и Python 3.11–3.13 — скрипт
поставит Python через Homebrew сам, если его нет. Модели (~850 МБ) скачиваются
при первом запуске.

## Как пользоваться

| Сочетание | Что делает |
|---|---|
| **⌃⇧Space** (зажать) | Держите и говорите; отпустили — текст на месте |
| **⌥Space** (нажать) | Нажали — говорите, нажали ещё раз — текст на месте |
| **Esc** | Отменить запись |

### Диктовка кода

Работает в приложениях со стилем «Код» (Xcode, VS Code, Терминал, iTerm — или
любое, выбранное во вкладке «Стиль»). Говорите вперемешку, как привыкли:

| Сказали | Получилось |
|---|---|
| let greeting равно кавычки привет кавычки | `let greeting = "привет"` |
| func load profile скобки открыть фигурную | `func loadProfile() {` |
| snake case user id равно 42 | `user_id = 42` |
| print открыть скобку user точка name закрыть скобку | `print(user.name)` |
| if count больше или равно 10 | `if count >= 10` |
| комментарий проверить, что профиль загружен | `// проверить, что профиль загружен` |

Знаки: равно, равно равно, не равно, плюс, минус, умножить, разделить, больше,
меньше, стрелка, точка, запятая, двоеточие, точка с запятой, (открыть / закрыть)
скобку, квадратную, фигурную, скобки, кавычки, подчёркивание, слэш, новая строка —
и то же по-английски (equals, dot, open paren…). Регистр: «кэмел кейс» (по
умолчанию), «паскаль кейс», «снейк кейс», «кебаб кейс», «капс», «слитно».
Просьба словами без английского и без знаков (например, чату в редакторе)
вставляется обычным текстом.

Стиль под приложения и словарь — во вкладках окна; сочетания, язык и микрофон —
в настройках (⌘,). Режим шёпота — в сайдбаре или ⌥⌘W.

Разрешения — два: **Микрофон** и **Универсальный доступ** (для вставки ⌘V в
чужое окно; без него текст ложится в буфер обмена).
