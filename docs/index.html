Код — голосом

В Xcode, VS Code и Терминале слушают сразу две модели: русские слова берутся у GigaAM, английские — у Parakeet, и всё склеивается по словам. Говорите вперемешку, как говорят программисты.

«Равно», «точка», «скобки», «кавычки» становятся знаками, английские слова — одним именем в camelCase. Другой регистр — командой: «снейк кейс», «паскаль кейс», «капс». Начали с «комментарий» — получится строка после //.

Чисто, со знаками и цифрами

Русский распознаёт GigaAM v3: он сам ставит запятые и точки и пишет числа цифрами. Английский — Parakeet TDT 0.6b. Смешанную речь язык определяет по кускам.

Слова-паразиты и повторы убираются до вставки.

Установка — как у обычного приложения

Скачали, перетащили в «Программы», открыли. Всё остальное FlowLocal сделает сам.

1

Скачайте

Один файл на любой Мак — Apple Silicon и Intel, около 3 МБ.

Скачать .dmg
2

Перетащите

Откройте .dmg и перетащите FlowLocal на папку «Программы».

3

Откройте

При первом запуске FlowLocal сам скачает Python и модели распознавания (~1 ГБ). Один раз, дальше без интернета.

macOS скажет, что не может проверить разработчика: приложение бесплатное и не куплено у Apple. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» — один раз.

~ % curl -fsSL https://raw.githubusercontent.com/romankandeevy/flowlocal/main/mac/install.sh | bash
== FlowLocal: установка ==
== собираю (несколько минут при первом разе) ==

Или одной командой: соберёт FlowLocal на вашем Маке из исходников, без вопросов от macOS. Нужны Command Line Tools — macOS предложит поставить их сама.

macOS 14+Apple Silicon или Intel — один и тот же файл.
Интернет — один разPython и модели (~1 ГБ) докачиваются при первом запуске.
Два разрешенияМикрофон — слышать. Универсальный доступ — вставлять ⌘V в чужое окно.
